# Photo Manager

也有桌面版：[PhotoManagerDesktop](https://github.com/alanwu-9582/PhotoManagerDesktop)（PySide6，直接讀本機資料夾，
另外還有景深模糊與 AI 風格提示詞這兩個需要模型的功能）。網頁版的「設定 → 關於」裡也有這個連結。

瀏覽器裡的照片工具箱：EXIF 檢視與統計、就地分類整理、批次改名、裁切旋轉、調整、EXIF 相框、照片色卡。
**照片不會上傳，也不需要下載回來** —— 直接讀取本機資料夾，分類完成後就地把檔案搬進子資料夾；
編輯類工具則是在 canvas 上做完再存回你自己的電腦。

版面與架構沿用 [OnlineTools](https://github.com/alanwu-9582/OnlineTools)：左邊側邊欄當功能列，
hash 路由換頁，每個工具一個資料夾。介面上只有控制項與狀態，沒有任何說明文字 ——
編輯類工具一律「左邊固定大小的照片區、右邊設定」，照片不動、只有右邊那一欄捲動；
窄螢幕則改成整頁捲動，並把照片區釘在上方。整理分類頁也是同一個做法：大圖固定，
只有右邊的縮圖欄會捲。

## 使用方式

因為要用到 File System Access API，頁面必須從 `http://localhost` 或 `https://` 開啟（`file://` 不行）。

```bash
node tools/serve.mjs 8010
```

然後打開 <http://localhost:8010>。（`python -m http.server` 也可以，只是它會讓瀏覽器快取舊的 JS／CSS，
開發時比較麻煩。）或直接部署到 GitHub Pages。

## 功能

### 照片管理

| 頁面 | 做什麼 |
| --- | --- |
| **照片檢視** | 縮圖牆、篩選、EXIF 欄位；點任一張就能送進編輯工具。翻到哪一頁才讀哪一頁 |
| **統計數據** | 焦段與 ISO 用直方圖、光圈／白平衡／格式用甜甜圈、器材與快門用橫條 |
| **整理分類** | 左邊大圖、右邊縮圖，鍵盤標記分類後一次套用（真的搬檔案） |
| **批次改名** | 用 token 組出新檔名，先預覽再一次改（真的改檔名） |
| **分類設定** | 分類的名稱、顏色、快捷鍵與動作；可以存成幾套設定檔隨時切換，也能匯出／匯入 JSON |
| **設定** | 外觀（跟著系統／淺色／深色）、每頁張數、本機資料、桌面版連結 |

流程：**開啟照片資料夾** → 到「整理分類」用 `1` `2` `3`… 標記、方向鍵切換、`⌫` 清除 →
按「套用整理」，照片就在原資料夾底下被移進各分類資料夾。
分類標記會存在瀏覽器裡（依資料夾名稱記憶），關掉重開不會不見。

照片來源列（開啟資料夾／選擇檔案）是跨頁共用的，所以固定在這幾頁的上方；換頁不會掉。
載入照片只走這一列上的按鈕 —— 整個視窗不再接受拖放，以免在整理照片時不小心把檔案丟進來就換了一批。
（編輯工具頁自己的照片區還是可以直接拖照片進去。）
來源、張數、EXIF 進度、已標記、已整理、容量也都在這一列上（沒有首頁，進來就是照片檢視）。
上一次開過的資料夾會記在 IndexedDB 裡：權限還在就自動接回來，權限掉了就在來源列上出現一顆
`↻ 資料夾名`，按一下重新授權再開。

支援 JPEG、TIFF、HEIC／HEIF。HEIC／HEIF 會在瀏覽器本機轉成可預覽的 JPEG，整理與搬移時仍保留原始檔；
照片不會送到伺服器。轉換層使用隨專案附帶的 [heic2any](https://github.com/alexcorvi/heic2any)。

HEIC 的 EXIF 是直接讀出來的，不經過轉檔：`js/engine/exif.js` 會走 ISOBMFF 的盒狀結構
（`meta` → `iinf` 找出型別是 `Exif` 的項目、`iloc` 查它在檔案裡的位置），拿到那一塊之後裡面
就是標準的 TIFF，交給原本那套 IFD 解析。所以就算縮圖解不開（例如沒有解碼器），
機身、鏡頭、光圈快門 ISO 這些還是讀得到。

### 分組

照片檢視的工具列上有「分組」：資料夾、拍攝日期、相機型號、鏡頭、分類、檔案格式，
以及**相似照片** —— 先依拍攝時間排好，相鄰兩張長得夠像（差異雜湊相差 12 個位元以內），
或是同一台相機 1.5 秒內連拍的，就歸成一組；挑連拍、挑同一個構圖時最好用。
差異雜湊是產生縮圖時順便算的，不會多讀一次檔案。

### 整理分類的大圖

左邊那張大圖可以**拖曳平移、滾輪縮放**，縮到最小就是「剛好放進框裡」（不會比原本更小），
連點兩下在放大與還原之間切換。

把右邊的縮圖**拖到大圖上**就變成左右對照，兩張並排。工具列上的鎖鏈是**連動開關**：
打開時兩邊一起縮放平移（比同一顆鏡頭不同光圈、或連拍的兩張很好用），關掉就各看各的。
對照中右邊那兩張縮圖都會是選取狀態，再點其中一張（或右上角的 ×）就收回單張。

按住 **space**（觸控裝置按工具列上的 ▷）會把大圖換成下一張，放開換回來。
畫面位置、縮放都不變，只有內容閃一下 —— 挑相似的連拍時用這個比左右切換快得多。

### 完整資訊（EXIF Inspector）

照片檢視**點照片本身**就是「完整資訊」，分頁列出這張照片知道的一切
（縮圖右下那顆工具鈕才是送進編輯工具）：

| 分頁 | 內容 |
| --- | --- |
| Basic | 檔名、路徑、格式、尺寸、百萬像素、檔案大小、拍攝時間、方向、容器 |
| Exposure | 焦段、35mm 等效、光圈、快門、ISO、曝光補償、曝光／測光模式、閃光燈 |
| Camera | 製造商、型號、韌體 |
| Lens | 鏡頭、焦段、光圈 |
| Color | 色域、白平衡、創意風格 |
| GPS | 緯度、經度、海拔（沒有 GPS 的照片不會有這個分頁） |
| Raw EXIF | IFD0 / Exif / GPS 的每一個標籤，含編號與名稱 |

Raw EXIF 是開這個視窗的時候才重新讀一次檔案的：一張照片幾百個欄位，整批掃的時候留著
對幾千張的資料夾是不必要的負擔。沒有寫 `PixelXDimension` 的檔案會實際解一次圖來量尺寸。

### 調整

參考 Lightroom 的「基本 / 色彩混合 / 效果」與 iPhone 的「攝影風格」，分成四個分頁：

| 分頁 | 內容 |
| --- | --- |
| 基本 | 色溫、色調、曝光、對比、亮部、陰影、白色、黑色、紋理、清晰度、去朦朧、細節飽和度、飽和度，加上**自動** |
| 風格 | 六種膚色基調 + 九種氛圍，用一塊方形控制板調「色調 × 色彩」，再用色盤調強度 |
| 色彩 | 八個色相各自的色相／飽和度／明亮度；顏色分級（陰影與亮部的色相、飽和、平衡） |
| 效果 | 暈影（總量、中點、羽化）、顆粒（總量、大小） |

順序跟 Lightroom 差不多：線性光做白平衡與曝光 → 去朦朧、攝影風格、亮部／陰影／白色／黑色、
對比、清晰度／紋理 → 顏色 → 暈影、顆粒。會看「附近」的那幾項（亮部／陰影的區域亮度、清晰度、
去朦朧）先在長邊 640 的縮圖上算成平滑圖再內插回去，所以預覽與原尺寸輸出看起來一樣。

**自動**不是猜公式，是直接在小圖上套用、量結果、再修正，反覆幾次：中間調只往 0.42 拉一部分
（本來就偏亮／偏暗的照片保留氣氛），對比只會加不會減。

計算全部在 Web Worker 裡：拖曳中只算長邊 460 的草稿，放開才算長邊 1280 的正式預覽，
所以滑桿一路拉下去畫面不會卡。輸出是原尺寸、一段一段算的，狀態列有進度。
按住 **space** 看原圖對照。

畫布左下角的**照片參數**有直方圖（含死白／死黑提示）、波形、向量示波器與代表色、曝光數字。

這一套計算是從桌面版的 `develop.py` 移植的，用同一組參數在兩邊跑過同一張圖比對過：
除了去朦朧（平均差 0.8/255）之外，其餘每個像素都一樣。

### 編輯工具之間的接力

每個編輯工具都有「暫存」：結果只留在記憶體裡、不寫檔，切到另一個編輯工具就接著用，
避免同一張照片被重複 JPEG 壓縮。接力中的工具上方會出現一條「正在編輯『某工具』的結果」，
旁邊一顆「改回原始」可以退回去。

### 批次改名

一條命名樣式 + 下面即時列出「原本 → 之後」。可以用的 token：

`{date}` `{time}` `{camera}` `{lens}` `{focal}` `{iso}` `{fnumber}` `{shutter}`
`{folder}` `{original}` `{index}`

例如 `{date}_{camera}_{index}` → `20260923_ILCE-6400_001.jpg`。
起始號碼與位數可以自己調，副檔名可以統一成大寫或小寫。
還有一個**正則取代**，寫成 `/DSC_(\d+)/i` + `IMG_$1` 這樣，套在 token 展開之後的名字上。

改名是不可逆的（檔案系統沒有復原），所以每一個新檔名都要先在預覽裡看得到；
撞名的那幾列會標紅，真的撞到時會自動補 `_1`。這個功能只在資料夾模式下能按。

### 篩選

照片檢視的「篩選」是一個對話框，一列一個條件：**欄位**（相機型號、鏡頭、ISO、拍攝日期、
檔案格式、分類、資料夾…）＋ **值**（例如 `ILCE-6400`，後面附出現次數）＋ **包含／不包含**。
同一個欄位的多個「包含」是或、不同欄位之間是且、「不包含」一律排除。
可以挑的值是從目前這批照片長出來的，所以不會選到零張。對話框的高度固定，增減條件不會讓它忽大忽小。

### 照片編輯

| 工具 | 做什麼 |
| --- | --- |
| **裁切旋轉** | 拉框裁切、拉桿轉正、90° 整轉與翻轉；比例可鎖 1:1／4:3／3:2／16:9／黃金比例等 |
| **EXIF 相框** | 讀出相機、鏡頭、曝光參數排成相框，可選下框／上框／上下框／全框／拍立得 |
| **照片色卡** | 取出照片的代表色，排成一張可以存下來的明信片 |

三個工具都可以拖曳、選檔案，或直接**從已載入的照片挑**一張 —— 剛整理完的那批照片就在手邊，
不必再去檔案總管找一次。

構圖格線（只畫在畫面上，不會進到輸出的檔案）：九宮格、黃金比例、黃金螺旋、黃金三角、
對角線法、細格線、中心十字。黃金比例與黃金螺旋都是一路切下最大的正方形（就是那張
1:1.618 的經典圖），可以換四個方向；裁切比例設成 1.618:1 時每段圓弧會剛好接上。

### 相容模式

Safari / Firefox 不支援直接存取資料夾，這時會退回舊流程：選擇檔案 → 標記 → 打包成 `.zip` 下載。
編輯類工具不受影響。

## 自訂分類

分類定義在 [`categories.json`](categories.json)：

```json
{
  "categories": [
    { "key": "1", "name": "機器人特寫", "folder": "機器人特寫", "color": "#87d1ff", "action": "move" }
  ]
}
```

| 欄位 | 說明 |
| --- | --- |
| `key` | 鍵盤快捷鍵，單一字元 |
| `name` | 顯示名稱 |
| `folder` | 要移動到的資料夾名稱（留空則用 `name`） |
| `color` | 標籤顏色 HEX |
| `action` | `move` 移動 / `copy` 複製（原檔保留）/ `keep` 只標記不動檔案 |

在「分類設定」頁可以直接新增、刪除、改顏色，設定會存進瀏覽器；也可以匯出 JSON 帶去別台電腦，
或按「重設為預設」回到 `categories.json` 的內容。

## 介面

顏色、字體、尺寸、元件與版面照桌面版的
[《介面設計規範》](https://github.com/alanwu-9582/PhotoManagerDesktop/blob/main/docs/%E4%BB%8B%E9%9D%A2%E8%A8%AD%E8%A8%88%E8%A6%8F%E7%AF%84.md)：

- 色票是 Apple HIG 的系統色，淺色／深色兩套跟著系統走，也可以在「設定」裡指定；強調色是 systemIndigo。
- 同一列的控制項一律高 30；圓角都在自己最短邊的 1/3 以內。
- 值的型別決定元件：連續的值用滑桿、有級距的用步進器、2–5 個互斥選項用分段控制、6 個以上用下拉。
- 畫面上不放操作說明，說明都在提示裡；空狀態只留一句話。
- 預覽畫布不論主題都是深色，照片的顏色才不會被淺色背景襯偏。
- 側邊欄展開 212、收合 60；底部有一條狀態列（來源 · 數量 · 狀態 · 進度）。
- Ctrl + 數字依側邊欄順序換頁。

字體是例外：桌面版用系統字，網頁版用 TASA Explorer（拉丁）+ IBM Plex Sans JP（中文）。

### 加一個工具

1. 開 `js/tools/<id>/index.js`，`export function mount(host)`（可回傳 cleanup），
   選填 `export const meta` 與 `export const styles`。
2. 在 `js/core/router.js` 的 `ROUTES` 加一筆，指定 `tool: "<id>"`、`label`、`icon`、`group`。

功能列、以及照片檢視上「用哪個工具開啟」那份清單，都是從 `ROUTES` 長出來的，不用另外註冊。

## 效能筆記

- 只讀檔案開頭 256KB 解 EXIF；縮圖優先由本機原圖縮到 480px，瀏覽器無法解碼原圖時才後備使用 EXIF 縮圖。
- HEIC／HEIF 預覽會按需轉碼並以 `WeakMap` 共用結果，原始檔不會被改寫。
- 一律使用 `objectURL`（不是 dataURL），縮圖與原圖各有 LRU 上限，超過就回收，幾千張照片也不會把記憶體吃爆。
- EXIF 與縮圖只在翻到那一頁時才讀。統計頁需要全部資料時，按「分析全部照片的 EXIF」再掃一次。
- 移動檔案優先用 `FileSystemFileHandle.move()`，同一個磁碟上是瞬間完成，不會真的複製資料。
- 編輯類工具的預覽固定畫在 1400px 的畫布上，匯出時才用原尺寸重畫一次。
- 照片區的高度是固定的（`--stage-h`），換照片、換方向都不會讓下面的控制項跳來跳去；
  照片本身則是量好可用空間後算出縮放，直幅橫幅都整張看得到。
